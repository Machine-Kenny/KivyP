# 🌌 KivyP — Galaxy Game

[![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)](https://www.python.org/)
[![Kivy](https://img.shields.io/badge/Framework-Kivy-green.svg)](https://kivy.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

**KivyP** is a cross-platform, galaxy-themed game built with **Python** and **Kivy**. The project demonstrates building interactive UIs, handling user input, and integrating multimedia assets (fonts, images, audio) using the Kivy framework.

## 🚀 Features
- 🎮 **Interactive gameplay** with a galaxy theme  
- 🎵 **Audio integration** (background & effects)  
- 🖼️ **Custom graphics** and sprites (images included)  
- ✨ **.kv layout files** separate UI from logic  
- ⌨️ **Keyboard / mouse / touch controls** via `user_actions.py`  

---

## 📂 Project Structure

KivyP/
- .vscode/ # Optional VS Code settings
- audio/ # Sound effects and music
- fonts/ # Custom fonts
- images/ # Sprites, backgrounds, icons
- galaxy.kv # Game screen layout
- menu.kv # Menu layout
- main.py # App entry point
- menu.py # Menu logic and navigation
- transforms.py # Animations and visual transforms
- user_actions.py # Input handling (keyboard/mouse/touch)
- README.md
